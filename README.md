# Elghodhben Iyed — Portfolio

Personal portfolio site. Built with Vue 3 + Vite.

## Stack

- Vue 3 (`<script setup>`)
- Vite
- Plain CSS (no framework) — design tokens in `src/style.css`
- Self-hosted fonts via `@fontsource` (IBM Plex Serif / Sans / Mono)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
